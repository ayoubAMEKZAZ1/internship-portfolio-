# Task 2: Customer Segmentation Using Unsupervised Learning

## Task Objective

Cluster customers based on spending habits (annual income and spending score) and propose marketing strategies tailored to each segment using the Mall Customers Dataset.

## How We Tackled the Task

We started by diving into the Mall Customers Dataset with some Exploratory Data Analysis to understand spending patterns. After cleaning the data, we applied K-Means Clustering to group customers into five segments based on 'Annual Income (k$)' and 'Spending Score (1-100)'. To make the clusters visually clear, we used PCA for a two-dimensional representation. From there, we brainstormed and suggested tailored marketing strategies for each segment, aiming to maximize engagement.

## Dataset Retrieval

The dataset was retrieved from the following source:

- Mall Customers Dataset
- https://www.kaggle.com/datasets/simtoor/mall-customers

## Results and Findings

We identified five distinct groups, including high-income/low-spending and low-income/high-spending customers. Strategies like luxury promotions for the former and discounts for the latter were proposed. The PCA visualization confirmed well-separated clusters, validating our segmentation approach.
