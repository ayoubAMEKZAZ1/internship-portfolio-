# Task 5: Interactive Business Dashboard in Streamlit

## Task Objective
Develop an interactive dashboard for analyzing sales, profit, and segment-wise performance using the Global Superstore Dataset.

## How We Tackled the Task
We started by cleaning and preparing the [Global Superstore Dataset](https://www.kaggle.com/datasets/apoorvaappz/global-super-store-dataset) to ensure data quality. Using Streamlit, we built a dashboard with filters for Region, Category, and Sub-Category, allowing users to explore the data dynamically. We then displayed key performance indicators—Total Sales, Profit, and Top 5 Customers by Sales—through interactive charts, making the insights accessible and engaging.

## Dataset Retrieval
The dataset was retrieved from the following source:  
- [Global Superstore Dataset](https://www.kaggle.com/datasets/apoorvaappz/global-super-store-dataset)

## Results and Findings
The dashboard successfully supported interactive filtering, revealing sales and profit trends across segments. Highlighting the top five customers by sales provided actionable insights, while the user-friendly design enhanced data storytelling and decision-making.
