# DevelopersHub Corporation - Data Science & AI/ML Engineering Internship

## Overview
Welcome to the Advanced Internship Tasks for the Data Science & AI/ML Engineering program at DevelopersHub Corporation. This repository contains solutions to a set of challenging tasks designed to provide practical exposure to real-world data science problems. The internship, due by 31st Aug 2025, requires completing at least three of the five advanced tasks, though completing all five is encouraged for deeper learning and a stronger portfolio. These tasks cover classification, clustering, time series forecasting, explainable AI (XAI), and business intelligence, utilizing popular datasets and industry-standard tools like pandas, numpy, scikit-learn, xgboost, shap, matplotlib, seaborn, Prophet, and Streamlit.

## Task Problematics
- **Task 1: Term Deposit Subscription Prediction (Bank Marketing)** - Tackling the challenge of predicting customer subscription to term deposits based on marketing campaign data, focusing on classification and model interpretability.
- **Task 2: Customer Segmentation Using Unsupervised Learning** - Addressing the need to segment customers by spending habits and devise tailored marketing strategies, emphasizing unsupervised learning and visualization.
- **Task 3: Energy Consumption Time Series Forecasting** - Exploring the prediction of household energy usage using historical patterns, highlighting time series analysis and model comparison.
- **Task 4: Loan Default Risk with Business Cost Optimization** - Investigating loan default likelihood and optimizing decision thresholds based on cost-benefit analysis, focusing on risk modeling and cost-based evaluation.
- **Task 5: Interactive Business Dashboard in Streamlit** - Developing an interactive dashboard for analyzing sales, profit, and segment performance, emphasizing business intelligence and data visualization.

This project aims to equip interns with hands-on skills, encouraging collaboration with mentors and showcasing work on LinkedIn or GitHub for enhanced visibility.
